# Client Content Checklist

Provide the following assets to fully launch the GAJO marketing site:

- [ ] Final logo SVG and brand imagery (hero background, class photography)
- [ ] Confirmed Qualified Trial offer (price, duration, bonuses)
- [ ] Testimonials (3–5 quotes with names/locations)
- [ ] Market-specific proof points or stats (CPL, show rates, member wins)
- [ ] Meta Pixel ID and Google Tag ID (required before launch)
- [ ] CRM webhook endpoint with field mapping (Airtable, HubSpot, or Pipedrive)
- [ ] Legal policy URLs and consent copy (if replacing the provided defaults)
- [ ] Operator contact info (email, phone, physical address)
- [ ] Optional: B-roll or class footage for the short-form engine
- [ ] Optional: Additional FAQs or objections to preload

Update [`data/site.json`](../data/site.json) once assets are available.
